Esse Bot Do Discord Fala O Que Deve Ser Feito Com Base No Comando Que Você Usa

- poluição - Mostra Carros Elétricos Ou Híbridos Que Você Pode Usar Para Diminuir A Poluição
- carros - Mostra Carros Que Não São Elétricos Mas Que Poluem Menos Do Que Outros Carros A Combustão
- poluição_adultos - Mostra O Que Adultos Podem Fazer Para Reduzir A Quantidade De Poluição
- poluição_adolescentes - Mostra O Que Adolescente Podem Fazer Para Diminuir A Poluição
